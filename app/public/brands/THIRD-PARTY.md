## Browser and operating system icons (2026-10-22)

The local `platforms/` SVGs are unmodified original-color (`default`) assets from
[The SVG](https://github.com/glincker/thesvg), pinned to commit
[`82f091cde35a754aa640a5df17069bea7e0d7884`](https://github.com/glincker/thesvg/tree/82f091cde35a754aa640a5df17069bea7e0d7884).
Downloads follow that commit's official `src/data/icons.json` manifest. No remote
icon CDN, package, or executable code is loaded at runtime. Each SVG was checked
for scripts, event handlers, external references, embedded images and foreign
objects before being saved. See `platforms/sources.json` for exact file URLs,
per-icon license metadata and available brand guidelines.

The repository/tooling MIT license is retained in `LICENSE.thesvg`. It does not
replace the individual icon licenses or grant trademark rights. Original brand
marks are used solely to identify browsers and operating systems. The upstream
[licensing](https://github.com/glincker/thesvg/blob/82f091cde35a754aa640a5df17069bea7e0d7884/LICENSING.md),
[legal](https://github.com/glincker/thesvg/blob/82f091cde35a754aa640a5df17069bea7e0d7884/LEGAL.md) and

are also retained in `platforms/THESVG-*.md`. Required CC attribution/license
texts are retained alongside the SVGs (unmodified texts from

### Retained local artwork where no appropriate color SVG is available

The pinned The SVG manifest has no product-specific icon for Yandex Browser, QQ
Browser, UC Browser, MIUI Browser, Huawei Browser or vivo Browser. Their existing
local assets in `images/icon/browser/` are retained; the Yandex/QQ messaging marks
are not substituted for browser products.

The SVG's macOS, iOS and HarmonyOS assets are black wordmarks rather than color
platform artwork. Existing `images/icon/os/` images are retained for macOS, iOS,
iPadOS, Chrome OS, Fire OS, HarmonyOS and Tizen. iOS and iPadOS retain their
existing color artwork. The retained black Apple mark uses a neutral white
surface for legibility in dark mode; it is not recolored. The SVG has no
iPadOS, Chrome OS, Fire OS or Tizen product-specific entry at this commit.

Single-color official brand defaults (such as Debian red, Arch blue, Fedora
blue or KaiOS purple) retain their original brand color; none uses `currentColor`
or the Font Awesome monochrome brand font. Unknown products and failed images
use the existing local generic UI fallback at the same 16 × 16 size.


## Traffic source icons (2026-10-22)

The bundled `sources/` icons are unmodified SVG assets from [The SVG](https://thesvg.org/),
pinned to [`82f091cde35a754aa640a5df17069bea7e0d7884`](https://github.com/glincker/thesvg/tree/82f091cde35a754aa640a5df17069bea7e0d7884).
The collection covers 68 common search, social, community and AI brands, with
original light/dark variants where upstream supplies them. Exact source URLs,
SHA-256 checksums, original brand links, guidelines and per-icon license metadata
are recorded in `sources/sources.json`. SVGs are served locally; no brand CDN is
loaded for these known sources. Each file was checked for a valid SVG root and
viewBox and for scripts, event handlers, embedded images, foreign objects and
external references before being saved.

Most entries declare MIT or CC0-1.0 in the upstream manifest. The corresponding
license texts and original The SVG licensing, legal and trademark notices are
retained in `sources/`. Douban retains the upstream `Custom` license metadata;
Microsoft Copilot retains its Microsoft trademark / nominative identification
notice. These marks identify traffic sources and do not imply endorsement.
Yahoo uses The SVG's original `yahoo-badge` asset; Hacker News uses its Y Combinator
mark (`y-combinator.svg`). There is no dedicated Bing Ads / Microsoft Advertising
mark at this revision, so that source family uses the Bing logo. Ask and 360
Search have no matching entry and continue to use the existing favicon fallback.
