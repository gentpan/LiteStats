# 原版界面对照 · 2026-10-31

本版采用原单人版的组件、CSS、图标、品牌和字体资源。当前有 104 个对应文件，其中 72 个保持字节一致；其余为 Go 接口适配、路由及用户明确要求的调整，来源和 SHA-256 记录在 `upstream-manifest.json`。

页脚以用户后续修改的版本为准：GitHub 与 Plost 均为 40×40px 区域，间距 0，图形颜色 `#a1a1aa`、悬停白色，手机端同样显示。公司、GitHub 和 Plost 链接分别指向 GiantAccel 官网、公开仓库及产品官网。

## 本轮其他页面对照

通过同一个 Chrome 标签页，依次加载原版显示组件和正式 Go 程序，使用相同临时测试数据：

- 账号偏好、安全、Mapbox，站点常规、可见性、安装、危险操作，站点列表、新建站点、活动日志，登录和首次初始化，分别检查桌面和手机。
- 额外检查桌面错误页，以及偏好、地图、安装等页面的深色模式。
- 共保存 34 组对照。检查的图标类名和字体、位置、宽高、间距、颜色、背景和圆角属性未发现差异，所查页面没有文档横向溢出。
- 额外检查安全及删除确认弹窗、备份创建及上传表单、手机设置侧栏展开。
- 原版与 Go 整页截图平均 RGB 绝对差：偏好设置 0.0014，安装页 0.0071（单通道范围 0–255）。安装页的采集说明按 SQLite 实际行为修正，示例服务端口也不同。

数据在 `dist/evidence/page-comparison.json`。对照只覆盖记录的页面状态、视口和属性，不声称对所有交互状态都做过逐像素验证。

## 开发参照

先启动 Go 本地测试实例在 3311 端口，再运行 `bun run reference`。用 `page=preferences`、`page=site-installation` 等参数选择页面，详见 `reference/README.md`。该开发页面只读取临时实例，不进入正式 Go 构建；开发服务拒绝转发写操作。它依赖工作区内保留的 `self-hosted/` 原版源码。

## 功能边界

场景模板及模板业务报表保持移除。原版报表外观保留，数据由 SQLite 查询提供；不虚构缺失数据。当前采集不记录省州、城市或整段查询参数，因此相关视图没有记录。Passkey、旧版备份导入、计划及云备份尚未移植，详见根目录 README。
